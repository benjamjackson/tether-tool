# Sony Camera Remote SDK

Headers (`include/`) and macOS libraries (`mac/`) from Sony's Camera Remote SDK
v2.02.00, downloaded by the project owner under Sony's license
(http://www.sony.net/CameraRemoteSDK/). They ship with Wrangle so it can control
Sony cameras. `libusb-1.0` is open source under the LGPL; see `libusb-COPYING.txt`.
